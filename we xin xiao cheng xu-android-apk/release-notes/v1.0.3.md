# Relax Block Puzzle Android v1.0.3

## 更新 / Update

- 优化拖动体验：点击方块时，方块从原始位置平滑抬升到手指上方，同时伴有轻微放大效果。
- Improved drag experience: when picking up a block, it smoothly lifts from its original position to above the finger with a slight scale-up animation.

- 拖动时 rack 中的原始方块不再显示，消除"两个方块"的视觉问题。
- The dragged block is now hidden from the rack during drag, eliminating the "two blocks" visual issue.

- 增大手指偏移距离，方块预览离手指更远，减少手指遮挡。
- Increased finger offset so the block preview is further from the finger, reducing finger occlusion.

- 清理项目中遗留的射击游戏代码和未使用音频文件。
- Removed legacy shooting game code and unused audio files.

## 核心功能 / Core Features

- 10x10 方块消除棋盘 / 10x10 block puzzle board
- 三档难度 / Three difficulty levels
- 本地最高分 / Local best scores
- 道具：刷新、清除、撤销 / Power-ups: refresh, clear, undo
- 本地福利码 / Local welfare code
- 离线游戏 / Offline Android play

## 声明 / Disclaimer

本项目为独立休闲方块消除游戏，与任何官方游戏品牌无关。
This is an independent casual block puzzle project and is not affiliated with any official game brand.

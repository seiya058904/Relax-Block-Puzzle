# 布局响应式人工验证清单

日期：2026-06-16

## Android 首页

- 管理员模式关闭：检查最高分区域与“开始游戏”不重叠。
- 管理员模式开启：检查“管理员模式”、难度、最高分、“开始游戏”、“怎么玩”、“设置”按顺序排列且不重叠。
- 在 360x640、375x667、390x844、412x915、430x932 或相近模拟器上检查短屏、窄屏和细长屏。
- 检查所有按钮仍可点击，且没有超出主面板。

## Android 游戏 HUD

- 分数分别测试：0、220、9999、999999。
- 分数脉冲时检查当前分数不覆盖“设置”和“暂停”。
- 检查当前分数、最高分和棋盘顶部之间没有重叠。
- 检查管理员模式标签不影响当前分数显示。

## 微信小程序 HUD

- 微信开发者工具中检查普通分数 0、220 的位置和视觉大小保持正常。
- 检查大分数 9999、999999 不覆盖暂停按钮。
- 检查大分数和分数脉冲不进入右上角微信菜单胶囊安全区。
- 检查棋盘、道具和候选方块区域没有无关变化。

## 真机检查

- Android 真机：检查不同分辨率和系统字体缩放下的首页和 HUD。
- 微信真机：检查菜单胶囊安全区、大分数和拖动手感。
- 本阶段自动化测试不验证 Canvas 像素级结果、真实触摸手感、真实音频或震动。

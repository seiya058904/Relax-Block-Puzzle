# Relax Block Puzzle Android v1.0.4

## 主要更新

- 优化方块拖动、放置和无效放置反馈。
- 新增清线得分、分数脉冲和新纪录提示。
- 优化 Android 首页在不同屏幕尺寸下的布局。
- 优化游戏顶部按钮、当前分数和最高分布局。
- 支持大分数自动适配，避免文字与按钮重叠。
- 修复撤回次数不消耗的问题。
- 修复撤回后候选方块或拖动状态异常的问题。
- 修复复活后仍能使用旧撤回状态的问题。
- 保留按需渲染和后台暂停恢复优化。

## 安装说明

下载 APK 后，在 Android 设备上允许安装来自该来源的应用，然后完成安装。

## 发布说明

- 本版本通过 GitHub Release 分发 APK。
- APK 文件不提交到 Git 仓库。
- 本项目为离线 Android 版本，不需要微信登录或云托管。

## 声明

本项目为独立休闲方块消除游戏，与任何官方游戏品牌无关。

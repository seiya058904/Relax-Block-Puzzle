# Relax Block Puzzle Android v1.0.9

## Changes

- Fixed WebView timer restoration when Android recreates the Activity in the same process.
- Kept the app-owned pause state at process scope so a new Activity resumes timers paused by the previous instance.
- Added lifecycle regression coverage for cold start, same-instance transitions, recreation, and repeated transitions.

## Verification

- Node parity and lifecycle regression tests passed.
- Android debug APK built with JDK 17 and Android SDK 34.
- APK asset boundary verification passed.
- Pixel 4 Android 14 API 34 emulator launch and interaction smoke passed without crashes.

APK files are distributed through the GitHub Release attachment and are not committed to the repository.

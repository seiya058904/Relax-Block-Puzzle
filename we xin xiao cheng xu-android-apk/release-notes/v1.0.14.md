# Relax Block Puzzle v1.0.14

This release brings the merged cross-platform presentation update to the Android preview, including the Classic Glow and Paper Geometry themes and the home-screen safe-area adjustment. Paper Geometry remains the default. The update preserves the current round when changing themes and does not change board rules, scoring, or saved-data keys.

## Android packages

- `Relax-Block-Puzzle-Android-v1.0.14-debug-preview.apk` is an installable Debug preview signed with the existing Android Debug certificate. It is intended for testing and is not a production-signed release.
- `Relax-Block-Puzzle-Android-v1.0.14-unsigned.apk` is the unsigned Release build. Android cannot install it until it is signed; it is not represented as a tested, production-ready package.
- Each APK is accompanied by a `.sha256` file for integrity verification.

The GitHub Release records the source commit and final artifact hashes. Physical Android devices and native WeChat interactions are outside emulator/browser validation.

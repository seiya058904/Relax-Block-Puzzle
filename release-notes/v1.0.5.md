# Relax Block Puzzle Android v1.0.5

## 主要更新

- 新增激光风格消行/消列特效。
- 清线时加入短暂蓄光、中心向两侧扫出的激光带、快速擦除淡出和少量碎光。
- 强化清线瞬间的视觉反馈，让消除更明显、更有冲击感。
- 优化特效节奏，总体动画更短促、集中，不遮挡棋盘判断。
- 保持 Android 和微信小程序版本的清线特效语义一致。
- 保留原有按需渲染机制，动画结束后不会持续无意义重绘。

## 规则与兼容性

- 未修改计分公式。
- 未修改清线规则。
- 未修改方块池、难度或候选块生成。
- 未修改撤回、复活、存档、音效、震动或管理员认证。
- 版本号更新为 `versionName 1.0.5` / `versionCode 5`。

## 安装说明

下载 `Relax-Block-Puzzle-Android-v1.0.5.apk` 后，在 Android 设备上允许安装来自该来源的应用，然后完成安装。

如果此前安装的是相同签名的旧版本，可以直接覆盖安装。若系统提示签名不一致，需要先卸载旧版本再安装；卸载通常会清除本地最高分和设置。

## 说明

本项目为独立休闲方块消除游戏，与任何官方游戏品牌无关。

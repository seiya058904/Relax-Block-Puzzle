# Relax Block Puzzle Android v1.0.8

## Changes

- Hardened three-platform input ownership and cancellation behavior.
- Corrected visual-coordinate drag distance and revalidated fallback candidates.
- Prevented writes after malformed or failed storage reads while preserving partial-object recovery.
- Added independent platform inventory validation for missing, orphaned, duplicated, and case-colliding paths.
- Unified Canvas ownership and included effective DPR in sizing keys.
- Stopped RAF scheduling while frozen and consumed terminal events without requiring another frame.
- Added parity and runtime regression tests covering these behaviors.

## Verification

- 157/157 Node tests passed.
- `npm run verify`, `npm run verify:assets`, and `git diff --check` passed.
- Chromium Web and Android asset regression passed with no console errors.

APK files are distributed through the GitHub Release attachment and are not committed to the repository.

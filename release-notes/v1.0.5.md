# Relax Block Puzzle Android v1.0.5

## 主要更新 / Highlights

- 新增激光风格消行/消列特效。
- Added laser-style row and column clear effects.

- 清线时加入短暂蓄光、中心向两侧扫出的激光带、快速擦除淡出和少量碎光。
- Clear effects now use a short charge, a center-out laser sweep, quick erase fade-out, and a few light fragments.

- 强化清线瞬间的视觉反馈，让消除更明显、更有冲击感。
- Improved line-clear feedback so clears feel more visible and responsive.

- 优化特效节奏，总体动画更短促、集中，不遮挡棋盘判断。
- Tuned the effect timing to be shorter and more focused without blocking board readability.

- 保持 Android 和微信小程序版本的清线特效语义一致。
- Kept the clear-effect semantics consistent between the Android and WeChat Mini Program versions.

- 保留原有按需渲染机制，动画结束后不会持续无意义重绘。
- Preserved the existing on-demand rendering behavior, so rendering stops after the animation ends.

## 规则与兼容性 / Rules And Compatibility

- 未修改计分公式。
- Scoring formulas were not changed.

- 未修改清线规则。
- Line-clear rules were not changed.

- 未修改方块池、难度或候选块生成。
- The block pool, difficulty settings, and candidate block generation were not changed.

- 未修改撤回、复活、存档、音效、震动或管理员认证。
- Undo, revive, save data, sound effects, vibration, and administrator authentication were not changed.

- 版本号更新为 `versionName 1.0.5` / `versionCode 5`。
- Version metadata was updated to `versionName 1.0.5` / `versionCode 5`.

## 安装说明 / Installation

下载 `Relax-Block-Puzzle-Android-v1.0.5.apk` 后，在 Android 设备上允许安装来自该来源的应用，然后完成安装。

Download `Relax-Block-Puzzle-Android-v1.0.5.apk`, allow installation from this source on your Android device, then finish the installation.

如果此前安装的是相同签名的旧版本，可以直接覆盖安装。若系统提示签名不一致，需要先卸载旧版本再安装；卸载通常会清除本地最高分和设置。

If an older version with the same signing certificate is already installed, you can install this version over it directly. If Android reports a signature mismatch, uninstall the old version first, then install this one. Uninstalling usually clears local best scores and settings.
